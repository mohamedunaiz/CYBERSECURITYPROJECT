## Projects

### 1. Network Sniffer

Captures and analyzes network traffic including IPs, ports, MAC addresses, protocols, DNS/HTTP activity, packet sizes and payload information.

**Stack:** Python, Scapy

### 2. Secure Coding Review

An intentionally vulnerable Flask application used for security education.

| ID | Vulnerability |
|---|---|
| V-01 | SQL Injection |
| V-02 | Stored XSS |
| V-03 | Hardcoded Credentials |
| V-04 | Weak Password Storage |
| V-05 | Path Traversal |
| V-06 | Broken Access Control |
| V-07 | IDOR |
| V-08 | Sensitive Information Disclosure |
| V-09 | Missing CSRF Protection |
| V-10 | Insecure Session Cookies |

**Stack:** Python, Flask, SQLite

### 3. Network Intrusion Detection System

A lightweight NIDS with rules for port scans, SYN floods, ICMP sweeps, DNS tunneling, SSH/HTTP brute force, UDP floods, path traversal, NULL scans and XMAS scans.

**Stack:** Python, Scapy, Flask, JSON, Multithreading

## Security Workflow

**Traffic → Capture → Analysis → Detection Rules → Alert → Investigation / Response**
